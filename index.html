Your inbox is waiting. Start with “Classify demo inbox”.

Learning uses only approved corrections, records their provenance, then invalidates the previous review. It never sends or routes a message.

03 / What this model can prove

Multinomial Naive Bayes learns word counts from labelled examples, with Laplace smoothing. Evidence compares the suggested label with the runner-up. It cannot understand intent, reliably handle languages beyond this English demo, or guarantee correct routing. Unknown vocabulary and close scores are surfaced, not hidden.

OpenAI Codex generated this new app and its synthetic fixtures under Aditya Mittal’s direction. No runtime generative model, cloud inference or user study. The proposal is a review assistant, not an autonomous helpdesk.
